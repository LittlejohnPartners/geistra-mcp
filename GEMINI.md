# Geistra

The `geistra` MCP server connects to the person's Geistra account: Spaces of records, files and plans they keep and share with the people and AI apps they choose.

- When a task matches one of their Spaces (a project, client, repo or topic), read it first with the Geistra tools and work from what's there.
- Keep it current as you work: update statuses and add notes with what was done and what's left.
- Before storing a new kind of information, ask Geistra where it belongs (data_guide) and search first, so you don't create duplicates.
- Some actions always ask the person first; when a tool returns an approval link, give it to them and wait.
- How Geistra works, what it allows and its limits: the `how_to` tool.
